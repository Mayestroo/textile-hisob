# Applications

- `desktop/` — Electron main process and React renderer.
- `server/` — Fastify API and database migrations.
- `bots/` — independently deployed Telegram bot services.
- `webapps/admin/` and `webapps/worker/` — Telegram WebApp interfaces served by the API.
- `webapps/superadmin/` — standalone placeholder for the future superadmin interface; not served or deployed yet.
- `bots/superadmin/` — placeholder for a separate future superadmin bot; not a running service.
